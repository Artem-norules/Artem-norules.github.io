Справка

Мобильное управление

Управление ПК с телефона через защищённый туннель.

Как это работает

На компьютере поднимается локальный веб-сервер (Flask). Для доступа из интернета используется ngrok (или прямой доступ в локальной сети). На телефоне открывается страница по ссылке; вход защищён PIN-кодом.

Включение

  1. В настройках включите мобильный доступ.
  2. Задайте PIN (хранится в конфигурации).
  3. При необходимости включите ngrok и укажите порт.
  4. Отсканируйте QR или скопируйте URL на телефон.

Можно включить автозапуск сервера вместе с приложением.

Возможности

Удалённые команды, быстрые действия, статус системы — в рамках того, что отдаёт API ассистента. Это не полноценный удалённый рабочий стол, а удобный пульт для частых операций.

Безопасность

  • Не сообщайте PIN и публичный URL посторонним.
  • Отключайте мобильный доступ, когда он не нужен.
  • В публичных сетях предпочитайте ngrok с ограниченным временем жизни сессии.
