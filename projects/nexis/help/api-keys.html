API-ключи

Как подключить собственных провайдеров ИИ и не зависеть от лимитов чужих ключей.

Зачем нужны свои ключи

Nexis AI работает с несколькими провайдерами. Свои ключи дают контроль над расходами, моделями и скоростью, а также позволяют использовать локальный Ollama без интернета.

Поддерживаемые провайдеры

  • Gemini — Google GenAI SDK. Ключ: GEMINI_API_KEY.
  • OpenAI-compatible — OpenAI, Groq, Together и любой endpoint с совместимым API. В настройках указываются base URL и модель.
  • Ollama — локальный сервер (по умолчанию http://127.0.0.1:11434). Ключ не требуется.

Где хранить секреты

Секреты не должны попадать в публичные конфиги. Используйте файл .env рядом с приложением (или переменные окружения):

GEMINI_API_KEY=ваш_ключ
# для OpenAI-compatible при необходимости:
# OPENAI_API_KEY=...

В интерфейсе: раздел настроек ИИ → выбор провайдера, base URL, модель. Значения из .env подхватываются автоматически.

Рекомендации

  • Для быстрых ответов удобен Groq (OpenAI-compatible endpoint).
  • Для приватности и офлайна — Ollama с подходящей моделью.
  • Системные инструкции (chat / voice) настраиваются отдельно и влияют на стиль ответов и вызов инструментов.
  • Не публикуйте ключи в скриншотах и логах. При утечке — сразу отзовите ключ у провайдера.

Проверка

После сохранения настроек выполните короткий запрос в чате или голосом. В логах приложения можно увидеть выбранного провайдера и ошибки подключения (без вывода самого ключа).
